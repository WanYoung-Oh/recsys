## 추천 앙상블 조합

**1순위: TiSASRec + BSARec + MB-STR + TIFU-KNN**

| 모델 | 가중치 (초기) | 역할 |
| ---- | ------------- | ---- |
| TiSASRec | 0.35 | CV=4.12 → 시간 간격이 핵심 신호 |
| BSARec | 0.30 | AAAI 2024 SOTA, 저역통과 FFT로 노이즈 제거 |
| MB-STR | 0.20 | view/cart/purchase 타입 임베딩 (이 데이터 고유 신호) |
| TIFU-KNN | 0.15 | 비신경망, 시간 감쇠 기반 → 앙상블 다양성 |

### 선택 근거

- **TiSASRec**: CV=4.12는 극히 높음 — 75%가 1일 이내, 10%가 2.6일 이상으로 시간 간격 분포가 심하게 이중 봉형(bimodal). SASRec 계열은 이 신호를 전혀 못 씀.
- **BSARec**: FEARec을 개선한 AAAI 2024 모델. 짧은 시퀀스(median=6)에서 FFT 저역통과가 위치 노이즈를 정리해 NDCG 안정성을 높임. SASRec의 슈퍼셋이므로 SASRec 별도 포함 불필요.
- **MB-STR**: 데이터에 view/cart/purchase 3종 행동이 명시적으로 존재. cart·purchase 위치에 loss weight까지 부여 → 구매 의도 시퀀스 학습에 직접 기여.
- **TIFU-KNN**: 신경망과 전혀 다른 귀납 편향(시간 감쇠 그룹 점수). 상위 1% 아이템이 25% 커버리지인 롱테일 환경에서 인기 아이템 편향을 교정하는 보완 역할.
